# 0058 gpui-pre 0.3.10

Date: 2026-10-26. Status: accepted.

Gpui, gpui_platform and gpui_web move to `gpui-pre =0.3.10`, Zed at 08cbb88, as GPUI Kit 0.8.1 pins them; `scripts/check.sh` failed to resolve Kit 0.8.1 beside 0.3.9. The snapshot renames `ScrollWheelEvent` to `ScrollEvent`, which gains a `source`, and `on_scroll_wheel` to `on_scroll`; `Modifiers::secondary` takes `cx` and reads the host; `Keystroke::unparse` takes the system whose modifier names it spells; `KeyBinding::new` and `Keystroke::parse` take `'static` text and fail on `secondary-`, which only `KeyBinding::load` and `parse_with_os` read. Ely's bindings keep 0.3.9's reading, the build's platform key, spelled at compile time by `ely_core::secondary!` and `word_key!`, so no binding panics and none waits for `cx`; this replaces 0039.
