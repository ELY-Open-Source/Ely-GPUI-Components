# 0061 gpui-pre 0.3.11

Date: 2026-11-05. Status: accepted.

Gpui, gpui_platform and gpui_web move to `gpui-pre =0.3.11`, Zed at f816e1f, as GPUI Kit 0.9.0 pins them; `scripts/check.sh` failed to resolve Kit 0.9.0 beside 0.3.10. No API Ely calls moved. `with_animation` now reads the executor's clock, not `Instant::now`, so a test moves an animation with `advance_clock`, never `thread::sleep`, and a reduced-motion entrance, 1 ms, runs only once the clock passes it. `KeyBinding::new` still takes `'static` text and only `parse_with_os` reads `secondary-`, so 0058's bindings stand; this replaces 0058.
