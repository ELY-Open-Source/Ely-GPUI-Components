# 0064 gpui-pre 0.3.14

Date: 2026-11-25. Status: accepted.

Gpui, gpui_platform and gpui_web move to `gpui-pre =0.3.14`, Zed at f126950, as GPUI Kit 0.11.0 pins them; `scripts/check.sh` failed to resolve Kit 0.11.0 beside 0.3.12. Ely 0.3.0 is unreleased, so the move joins its breaking change. Gpui's `Path` lost its unit parameter, and gpui now implements `IntoElement` for every `Element`, so Ely's five identity impls go. The keymap, the atlas, modal nodes and `with_animation` did not change, so 0061's notes stand. `vendor/gpui-pre-macos` is 0.3.14 as published, then the frame link logs and CVDisplayLink pacing replayed. This replaces 0063.
